# Coastal greenhouse gas exchange across Chinese blue-carbon ecosystems

This repository contains the analysis code used to quantify and interpret greenhouse-gas (GHG) exchange across Chinese coastal blue-carbon ecosystems, including mangroves, salt marshes, unvegetated tidal flats, and seagrass meadows.

The repository includes two complementary analyses:

1. **Monte Carlo upscaling and climate-equivalent assessment** of CO2, CH4, and N2O emissions, including GWP100/GWP20 sensitivity and non-CO2 offsets of carbon-burial climate benefits.
2. **XGBoost + SHAP + generalized additive model (GAM) analysis** to identify nonlinear environmental responses and data-driven thresholds for CO2, CH4, and N2O.

## 1. Monte Carlo analysis

`Coastal_GHG_MC.ipynb` performs province-by-ecosystem Monte Carlo upscaling of water-air GHG fluxes and evaluates the climatic effect of CH4 and N2O relative to carbon burial.

### Main workflow

The notebook:

- reads province × ecosystem GHG and area inputs;
- harmonizes province names and assigns provinces to broad coastal regions;
- represents uncertain ecosystem area using fixed values or uniform distributions between reported lower and upper estimates;
- fills missing gas-specific province × ecosystem fluxes using same-ecosystem donor pools, prioritizing regional donors when at least two are available and otherwise using national same-ecosystem donors;
- propagates area and missing-flux uncertainty through 10,000 Monte Carlo simulations;
- converts carbon burial from Gg C yr-1 to Gg CO2-eq yr-1 using 44/12;
- calculates ecosystem- and national-scale CO2, CH4, N2O, and combined non-CO2 climatic effects;
- calculates the percentage offset of carbon-burial climate benefit by signed CH4 + N2O emissions;
- evaluates sensitivity to 20-year versus 100-year global warming potential (GWP) horizons; and
- exports Monte Carlo draws, summaries, donor information, diagnostics, and method notes to an Excel workbook.

### Monte Carlo settings

- Number of simulations: `10,000`
- Random seed: `20260913`
- CH4 GWP100: `27.2` (legacy coefficient retained to reproduce the manuscript baseline)
- CH4 GWP20: `79.7`
- N2O GWP100/GWP20: `273`
- CO2 GWP: `1`

National GWP20 results are generated by paired reweighting of CH4 within the archived national GWP100 Monte Carlo draws. N2O and carbon-burial values are retained within the same draws.

## 2. XGBoost + SHAP + GAM analysis

`Coastal_GHG_SHAP_GAM.R` evaluates nonlinear relationships between greenhouse gases and environmental predictors.

### Predictor variables

The script uses the following predictors:

- Temperature (`Temp`)
- Salinity (`Salinity`)
- pH (`pH`)
- Dissolved oxygen (`DO`)
- Dissolved inorganic phosphorus (`DIP`)
- Dissolved silicate (`DSi`)
- Ammonium (`NH4`)
- Oxidized nitrogen (`NOx`)
- Sediment grain size (`Grain_size`)
- Sediment organic carbon (`SOC`)
- Sediment organic nitrogen (`SON`)
- Latitude (`Latitude`)
- Longitude (`Longitude`)

Response variables are `N2O`, `CH4`, and `CO2`.

### Main workflow

For each selected gas-environment relationship, the script:

1. trains an XGBoost regression model (`reg:squarederror`);
2. obtains SHAP interaction values from the fitted model;
3. extracts the diagonal SHAP interaction term for the focal variable as its SHAP main effect;
4. fits a GAM to the relationship between the focal environmental variable and its SHAP main effect using `mgcv::gam(..., method = "REML")`;
5. predicts the fitted GAM response and 95% confidence interval over 500 points;
6. identifies a candidate threshold from the fitted curve:
   - a **turning point** when the first derivative changes sign, selecting the candidate with the strongest local curvature; or
   - a **knee point** at the largest absolute second derivative when no sign change occurs;
7. reports GAM effective degrees of freedom, P value, adjusted R2, deviance explained, plot-based R2, RMSE, threshold value, and threshold type; and
8. exports the combined figure and summary table.

### Relationships evaluated by default

- N2O ~ NOx
- N2O ~ NH4
- CH4 ~ DO
- CH4 ~ NOx
- CO2 ~ Temperature
- CO2 ~ DO

### Required input file

The R script currently expects:

```text
Data.xlsx
```

The file must contain all predictor and response columns listed above.

## Reproducing the analyses

### Monte Carlo analysis

Place the required Excel input files in the same directory as `Coastal_GHG_MC.ipynb`, start Jupyter, and run all notebook cells in order:

```bash
jupyter notebook Coastal_GHG_MC.ipynb
```

### SHAP + GAM analysis

Place `Data.xlsx` in the same directory as `Coastal_GHG_SHAP_GAM.R`, then run:

```bash
Rscript Coastal_GHG_SHAP_GAM.R
```

The script will automatically install missing R packages if needed.

## Reproducibility notes

- The Monte Carlo analysis uses a fixed random seed (`20260913`).
- Directly observed province × ecosystem mean fluxes are treated as fixed in the component-level Monte Carlo analysis; the implemented uncertainty therefore does not include station-level resampling uncertainty for those observed combinations.
- Missing province × ecosystem gas fluxes are represented using gas-specific donor pools rather than parametric distributions.
- Ecosystem-area uncertainty is propagated only where multiple area estimates are available.
- The climate-offset calculation compares signed CH4 + N2O CO2-equivalent exchange with carbon-burial climate benefit. It should not be interpreted as a complete ecosystem greenhouse-gas balance.
- The SHAP-GAM threshold routine identifies descriptive candidate turning/knee points in fitted SHAP response curves. These thresholds should be interpreted as model-derived nonlinear response features rather than causal ecological breakpoints.
